# Beauty Application

Beauty Application este o aplicatie Python pentru
gestionarea produselor cosmetice.

## Functionalitati

- Adaugarea produselor cosmetice
- Cautarea produselor
- Stergerea produselor

## Tehnologii utilizate

- Python
- Git
- GitHub

## Dezvoltare

Proiect realizat in echipa de doi studenti,
folosind branch-uri separate si Pull Requests.
